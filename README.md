# 📧 Django Сервис Управления Рассылками

## 📌 Описание проекта

Этот сервис позволяет пользователям управлять email-рассылками, создавая, редактируя и отслеживая их выполнение.
Веб-приложение разработано на Django и поддерживает регистрацию пользователей, управление клиентами и сообщениями, а
также сбор статистики о рассылках.

## 🚀 Функционал

### 1. 👥 Управление клиентами

- Добавление, просмотр, редактирование и удаление получателей рассылки.
- Поля модели клиента:
    - Email (уникальный).
    - ФИО.
    - Комментарий.

### 2. ✉️ Управление сообщениями

- CRUD-операции с сообщениями.
- Поля модели сообщения:
    - Тема письма.
    - Тело письма.

### 3. 📅 Управление рассылками

- CRUD-операции с рассылками.
- Поля модели рассылки:
    - Дата и время первой отправки.
    - Дата и время окончания.
    - Статус ("Создана", "Запущена", "Завершена").
    - Привязка к сообщению и получателям.
- Включена автоматическая отправка через Celery.

### 4. 📤 Отправка сообщений

- Вручную через интерфейс.
- Из командной строки (кастомной командой Django).

### 5. 📊 Статистика

- Отчёты по успешным и неуспешным попыткам рассылок.
- Количество активных рассылок и уникальных клиентов.

### 6. 🔐 Аутентификация и права доступа

- Регистрация и вход пользователей через email.
- Разграничение ролей:
    - **Пользователь** – управляет только своими данными.
    - **Менеджер** – может просматривать всех клиентов и рассылки, но не редактировать их.

### 7. ⚡ Кеширование

- Настроено серверное кеширование для ускорения работы.

## 🛠 Технологии

- **Backend:** Python, Django, Celery, Redis
- **Database:** PostgreSQL
- **Frontend:** Django Templates, Bootstrap

## 📌 Установка и запуск

```sh
# Клонирование репозитория
git clone https://github.com/LeojBang/mailing_management_service.git

# Создание виртуального окружения
python -m venv venv
source venv/bin/activate  # Linux & Mac
venv\Scripts\activate  # Windows

# Установка зависимостей

poetry install

# Применение миграций
python manage.py migrate

# Запуск Celery
celery -A config worker --loglevel=info

# Запуск сервера
python manage.py runserver
```

## 📌 API Эндпоинты

| Метод  | URL                          | Описание                 |
|--------|------------------------------|--------------------------|
| `GET`  | `mailing_recipient/`         | Список клиентов          |
| `POST` | `mailing_recipient/create//` | Создание клиента         |
| `GET`  | `message/`                   | Список сообщений         |
| `POST` | `/message/create/`           | Создание сообщения       |
| `GET`  | `mailing/`                   | Список рассылок          |
| `POST` | `mailing/create/`            | Создание рассылки        |
| `POST` | `mailing/<int:pk>/`          | Ручная отправка рассылки |
